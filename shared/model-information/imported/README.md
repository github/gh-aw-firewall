# Committed legacy catalog capture

`legacy-models-dev.snapshot.v1.json` is generated by
`importPinnedLegacySnapshot()` from the committed
`containers/api-proxy/models.dev.catalog.json` bytes. The legacy filename says
`models.dev`, but the actual input has an OpenRouter-shaped `{ "data": [...] }`
payload, not a models.dev provider-map format. Its Git blob ID is
`7aadc2a15168959d020df4252b650337536e1c1d`; the input SHA-256 is
`e99d729367dd9dc0862d24c2fa1a2407e994febf683bb159b91031743b30fd38`.
The schema-required `retrievedAt` is **repository capture time**: the Git
commit timestamp `2026-10-19T17:20:11-07:00`, **not** an asserted upstream
retrieval time. The upstream retrieval time and license have not been verified.
Regenerating this snapshot must not replace that time with the regeneration
time. New upstream snapshots need separately verified metadata.

Importer v1 accepts 355 of 366 entries, rejects 11, and reports no
normalization collisions. Eight rejected entries use a leading `~` provider
prefix outside the provider identity contract; three `openrouter` entries
have negative sentinel prices. Unsupported charges such as web search,
image, audio and internal reasoning are omitted rather than assigned an
unverified accounting unit. Missing prices never become zero.

The shared schema requires `lifecycle.status` and `modelType` for every record.
Imported `active` means **listed in the captured file**, not currently
available, deployable, or supported by the provider; `other` is a conservative
model-type placeholder. No availability, aliases, replacement, harness,
reasoning, or wire-protocol support is inferred. Imported prices are
`native-api`-scoped source facts only, not Copilot prices.

The compiler should consume this snapshot only as a lower-priority imported
source after validating it with `validate('importedSnapshot', snapshot)`,
checking the pinned source bytes' SHA-256 and count/collision report. Do not
add `require('shared/model-information/...')` to API-proxy runtime files:
the proxy image does not ship the shared source tree. Instead, compile any
needed provider-qualified pricing projection into the proxy's packaged
generated assets, behind parity/shadow comparison before changing matching
behavior. Do not insert this snapshot among maintained `sources/*.json`
records: those records use different authority and are compiler inputs for
reviewed facts.
